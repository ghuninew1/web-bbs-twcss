## 📖 เกี่ยวกับโปรเจกต์ (About The Project)

**web-bbs-twcss** เป็นเว็บแอปพลิเคชันอย่างเป็นทางการของ **Big Brain Studio** (เดิมชื่อ *Big Brain Pictures* ก่อตั้งขึ้นเมื่อปี 2013)

เว็บไซต์นี้พัฒนาขึ้นใหม่โดยใช้ **React 19**, **Vite**, **Tailwind CSS** และ **React Router v7** เพื่อนำเสนอผลงานระดับมาสเตอร์พีซ, แนะนำสตูดิโอและบริการ, อัปเดตข่าวสารกิจกรรม, ประกาศรับสมัครงาน รวมถึงระบบนามบัตรดิจิทัล (Digital Name Cards) พร้อมประสิทธิภาพความเร็วสูงและ Responsive Design ที่รองรับทุกขนาดหน้าจอ

🔗 **เว็บไซต์หลัก**: [https://www.bigbrain-studio.com](https://www.bigbrain-studio.com)

## ✨ ฟีเจอร์หลัก (Key Features)

- 🏠 **Home & Showreel**: แสดงผลงานวิดีโอ Showreel ล่าสุดผ่านระบบ Video Embed พร้อมส่วนจัดแสดงพันธมิตรและลูกค้า (Partner Carousel)
- 🏢 **Studio & Story**: ถ่ายทอดเรื่องราว ประวัติความเป็นมา ทีมงาน วิสัยทัศน์ และวัฒนธรรมของสตูดิโอ พร้อมเอฟเฟกต์การเปลี่ยนผ่าน (Custom Animations)
- 🎬 **Our Work (Portfolio Showcase)**:
  - รวมผลงานแอนิเมชัน, ซีรีส์, สปอตโฆษณา และงาน CG โครงการสำคัญ (อาทิ *Blink Blink, Gift of The Land, Royal Project Foundation, Wisdom King, Mythophobia Online Game, EGAT Smart Grid, PTT OR, Tan Land, Conan-O*, ฯลฯ)
  - หน้ารายละเอียดผลงานเฉพาะเจาะจง พร้อมสไลด์ตัวอย่าง, วิดีโอ และระบบ **Image Zoom Modal** ขยายดูภาพผลงาน
- ⚙️ **Services**: แสดงขอบข่ายการบริการด้าน Creative Design, 2D/3D Animation, VFX, Multimedia Production
- 📰 **News & Activities**: ระบบกระจายข่าวสารและอัปเดตกิจกรรม พร้อม Modal แสดงรายละเอียดข่าวและสื่อมัลติมีเดีย
- 💼 **Jobs & Careers**: ประกาศรับสมัครบุคลากรร่วมทีม แสดงตำแหน่ง คุณสมบัติ และรายละเอียดการสมัคร
- 📢 **Announcements**: ข้อมูลและประกาศข่าวสารสำคัญจากทางสตูดิโอ
- 📞 **Contact Us**: ข้อมูลที่อยู่สำนักงาน แผนที่ ช่องทางติดต่อด่วน และลิงก์โซเชียลมีเดียครบวงจร (Facebook, YouTube, Instagram, WhatsApp, Vimeo, LinkedIn)
- 📇 **Digital Business Cards (E-Cards)**: หน้านามบัตรดิจิทัลสำหรับทีมงานแต่ละบุคคล (เช่น `/card`, `/cardPtum`, `/cardPpang`, `/cardPnote`, `/cardPtood`, ฯลฯ) รองรับการเปิดผ่าน QR Code บนสมาร์ตโฟน
- 🚀 **Performance & Modern UI**:
  - โหลดภาพและวิดีโอแบบ Lazy Loading พร้อมฟอร์แมตภาพสมัยใหม่อย่าง `.avif`
  - รองรับ Scroll-to-Top และ Intersection Observer เพื่อตรวจจับการมองเห็นและเริ่มเล่นแอนิเมชันอย่างลื่นไหล

| **Icons** | [@heroicons/react](https://heroicons.com/) | ชุดไอคอน SVG แบบคมชัดจาก Tailwind Labs |
| **Code Quality** | [ESLint 9](https://eslint.org/) | ตรวจสอบคุณภาพโค้ดตามมาตรฐาน ECMAScript/React |
| **Package Manager** | [pnpm](https://pnpm.io/) | Fast & disk space efficient package manager |

│   │   │   ├── home/           # หน้าแรก + พาร์ตเนอร์ (Home & HomePartner)

│   ├── App.jsx                 # นิยาม Route และการกำหนดค่า BrowserRouter

## 🚀 การติดตั้งและเริ่มต้นใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)

- [Node.js](https://nodejs.org/) (เวอร์ชัน 18.0.0 หรือสูงกว่า)
- [pnpm](https://pnpm.io/) (แนะนำ) หรือ `npm` / `yarn`

### ขั้นตอนการรันโปรเจกต์

1. **โคลนคลังโค้ด (Clone Repository)**
   ```bash
   git clone https://github.com/ghuninew1/web-bbs-twcss.git
   cd web-bbs-twcss
   ```

2. **ติดตั้ง Dependencies**
   ```bash
   pnpm install
   # หรือใช้ npm:
   # npm install
   ```

3. **รัน Development Server**
   ```bash
   pnpm dev
   # หรือใช้ npm:
   # npm run dev
   ```
   จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:5173/`

4. **ตรวจสอบโค้ดด้วย Linter**
   ```bash
   pnpm lint
   ```

5. **สร้างไฟล์สำหรับ Production (Build)**
   ```bash
   pnpm build
   ```

6. **ทดสอบรัน Production Preview**
   ```bash
   pnpm preview
   ```

## 📜 สคริปต์คำสั่ง (Available Scripts)

ในไฟล์ `package.json` มีสคริปต์คำสั่งสำหรับใช้งานดังนี้:

| คำสั่ง | รายละเอียด |
| :--- | :--- |
| `pnpm dev` | รัน Local Development Server ด้วย Vite พร้อม Hot Module Replacement (HMR) |
| `pnpm build` | คอมไพล์และแพ็กเกจไฟล์สำหรับ Production ลงในโฟลเดอร์ `dist` |
| `pnpm preview` | เปิด Local Web Server เพื่อพรีวิวไฟล์ Build ที่ถูกสร้างขึ้น |
| `pnpm lint` | รัน ESLint ตรวจสอบความถูกต้องและคุณภาพของโค้ด `.js` และ `.jsx` |

## 🌐 การเพิ่มประสิทธิภาพและการค้นหา (SEO & Metadata)

- มีการกำหนดค่า Meta Tags, Open Graph (`og:image`), Twitter Card และ Canonical URL ครบถ้วน
- รองรับ Structured Data ตามมาตรฐาน [Schema.org](https://schema.org/) ประเภท `LocalBusiness` (JSON-LD) ช่วยเพิ่มโอกาสแสดงผลบน Google Rich Results
- รองรับ Responsive Favicon และ Web Manifest (`manifest.json`) สำหรับการทำงานบนอุปกรณ์พกพา
